# Medteria — 医学を、一問ずつ。

2025年度卒業試験の医学過去問を演習する、モバイル中心の静的SPAです。添付 `q_and_a_sample.json` の6問（1、2、3、4、7、9）だけを収録しています。

## 開発とGitHub Pages用ビルド

Node.js 22.12以上を使用してください。

```bash
npm ci
npm run dev
npm test
npm run build:pages
```

編集用のReact・TypeScriptソースは `src/`、元のアセットは `public/` にあります。
`npm run build:pages` は型チェック後、ベースパス `/medbase-002/` で静的サイトを `docs/` へ生成します。
ソースを変更したら、必ずこのコマンドを再実行し、ソースと更新された `docs/` を一緒にコミットしてください。
`docs/` はGit管理対象です。生成されたファイルを直接編集しないでください。

通常の `npm run build` は汎用ホスティング向けの `dist/` を生成します。
日本語フォント、問題画像、PDF、pdf.js workerを同梱し、外部API・CDN・ログインは不要です。
HashRouterを使用するため、`#/practice` や `#/results` への直接アクセスと再読み込みに対応します。

## GitHub Pagesで公開する

1. このリポジトリで `npm run build:pages` を実行します。
2. 編集用ソースと `docs/` をコミットし、`Igaki12/medbase-002` の `main` へpushします。
3. GitHubの **Settings → Pages → Build and deployment** を開きます。
4. **Source: Deploy from a branch**、**Branch: main**、**Folder: /docs** を選び、**Save** を押します。
5. デプロイ完了後、https://igaki12.github.io/medbase-002/ を開きます。

公開フォルダー名は小文字の `docs` です。`docs/index.html` と `docs/.nojekyll` を含めて保存します。
独自ドメインやGitHub Actionsによる独自ビルドは設定していません。
[GitHub公式の設定手順](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

GitHub PagesのURLで学習データは初期状態になります。既存のSitesサイトから履歴を移す場合は、
そちらの「データ管理」でエクスポートし、GitHub Pagesサイトでインポートしてください。
保存はブラウザ・オリジン単位です。学習履歴はこのリポジトリに含めていません。

## 保存と差し替え

学習データはlocalStorageの `medica.learning.v1` に保存し、問題キーは `q_and_a_sample:${q_id}` です。`DataAdapter` は `src/domain.ts`、`StorageAdapter` は `src/state.ts` に定義しています。将来のAPI／DBへの差し替えを想定し、UIからlocalStorageを直接操作しません。

回答履歴、ブックマーク、メモ、誤り報告、表示設定、出題設定、プリセット、演習セッションをまとめてバックアップします。保存はブラウザ・オリジン単位です。ローカルプレビューの学習履歴を公開URLへ移す場合は、エクスポート／インポートを使用してください。

## 採用した仮定と未対応

- JSONは6問、記述式0問。全問の `answer_source` は `official`。公式解答との不一致は0問。
- 連問情報があるのは問題7のみ。問題6・8と共通症例はJSONにないため、追加せず「連問2/3・共通症例は未収録」と表示します。
- 完全な連問・記述式の共通UIはテスト用データで検証済み。テスト用問題は本番の問題一覧に入りません。
- デモの他ユーザー統計は実在する集計ではありません。「全期間」の日別グラフは最低90日、学習履歴がそれより古ければ最初の記録から表示します。
- 誤り報告は外部送信せず、この端末に保存します。
- 未対応：問題アップロード、PDFからの抽出・再生成、ジョブAPI、問題セットの追加・削除、アプリのログイン、サーバー集計、端末間自動同期。

## ホームのデザイン調整

ヒーローの装飾線と問題セットの表紙は元のデザインへ復元しました。見出しを700ウェイトにし、本文・ボタンが順にスライドインする演出を追加しました。演出OFFとprefers-reduced-motionで無効になります。ヒーローには藍色の半透明レイヤー、細いハイライトと陰影を追加し、4つの学習指標カードは透明な背景と細い枠線にしました。

## 正解・完了時の演出

正解時は22個、リザルトは32個の幾何学パーツが中心から外へ飛び出します。角度・距離・開始時間・速度・サイズ・回転方向・回転量・横への漂い・落ち方をパーツごとに変え、演出のたびに新しい組み合わせを作ります。円・四角・三角・線と既存のゴールド／青緑を維持。およそ1〜2.6秒で消え、クリックは透過し、次の操作で演出を停止します。演出OFFとprefers-reduced-motionを尊重します。
